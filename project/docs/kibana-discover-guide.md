# Kibana Dashboards & Drilldown Guide

XML Insight Lab provisions **14 Kibana dashboards** showcasing **28 distinct visualization & interactivity paradigms** (`lnsDatatable`, `lnsMetric`, `lnsGauge` Arc, Horizontal Bullet & Full 360° Circle Ring, `lnsPie` Treemap, Mosaic/Marimekko, Waffle Grid, Multi-Ring Sunburst, Donut & Pie, `lnsXY` Stacked Bar, Horizontal Bar, 100% Percentage Stacked Bar, 100% Percentage Stacked Area, Dual-Axis Combo Bar+Line, Stacked Area & Line, TSVB `top_n` Progress Bars & `metric` KPI, Classic `tagcloud`, Classic 4-in-1 Multi-Bucket Circular `gauge`, Classic 2D Color `heatmap`, Interactive `markdown` Navigation & Preset Buttons, Chained Hierarchical Dropdowns `optionsListControl`, Numeric Two-Handle Range Sliders `rangeSliderControl`, Context Drilldowns `DASHBOARD_TO_DASHBOARD_DRILLDOWN`, Data View Color Badges & Clickable `🔗 run.id` Hyperlinks `fieldFormatMap`, and custom `vega` Bubble Matrix, Dual-Axis Pareto Curve, Campaign Swimlane Health Matrix, 5-Dimension Parallel Coordinates Flow & Vega Built-In HTML Radio/Select/Range Inputs) backed by **7 Data Views**. All dashboards focus strictly on **errors, test benches, suites, software versions, and root-cause analysis**.

## Recommended Analysis Path

1. Start in **01. Nightly Overview**, **10. Campaign & Bench Health Matrix**, or **11. Error Classification & Root Cause Analysis** to spot missing/partial reports, bench hotspots, or `RELEVANT` vs. `KNOWN_ISSUE` fault dispositions.
2. Open **08. Bench & Suite Failure Matrix**, **09. TestCase & Error Matrix**, or **07. Software Version & Regression Lab** to compare aggregated failure counts across `test_bench.id` × `suite.name` × `software.version` × `error_mapping.rule_id`.
3. Filter by a specific `run.id` or `test_case.name` in **03. Run Details** and **04. Test Details** (keep time range at **Last 7 days**) to inspect `init` → `suite` → `deinit` step outcomes and mapped error messages.
